# 🎓 AI & DS Department Website

A modern, responsive, and interactive website developed for the **Department of Artificial Intelligence & Data Science (AI & DS)** at **CMS College of Engineering**.

This project serves as a digital platform to showcase the department's academic excellence, faculty, infrastructure, student achievements, placements, industry collaborations, and various departmental activities.

---

## 📖 About the Project

The AI & DS Department Website is designed to provide students, faculty members, parents, alumni, and visitors with comprehensive information about the department through an intuitive and responsive interface.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/subalakshmiboopathi-hue/AI-DS.git
```

### Navigate to the Project

```bash
cd AI-DS
```

### Run the Website

Open the `index.html` file in your preferred web browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for a better development experience.
